# Linux 多进程即时通讯系统

本项目对应《Linux 操作系统编程》第 5 题“简易聊天室（多进程版）”。支持邮箱注册、用户名和密码登录、在线列表、群聊和私聊。群聊消息与群文件通知会保存在服务端，重启后仍可查询。群文件支持上传、下载、进度显示、下载续传与 SHA-256 校验。

## 编译与运行

使用 Linux 或 WSL Ubuntu，需安装 GCC、Make、Python 3 和 GNU Coreutils（提供 /usr/bin/sha256sum）。在 WSL 的终端执行：

~~~bash
cd '/mnt/d/linux/结课作业'
make
./server
~~~

在网页注册演示用账号后，另开 WSL 终端，分别在项目目录执行以下命令。终端会提示输入注册时设置的密码，输入时不回显。

~~~bash
./client 127.0.0.1 9000 alice
./client 127.0.0.1 9000 bob
./client 127.0.0.1 9000 carol
~~~

服务端默认监听 127.0.0.1。聊天使用 9000 端口，文件传输使用 9001 端口。可用 ./server 127.0.0.1 9100 ./demo-data 更改配置，文件端口始终为聊天端口加一。用户名可包含字母、数字、下划线和连字符，长度为 1–31 字节。

## 网页聊天室

先在一个 Ubuntu（WSL）终端启动服务端 ./server。在项目目录的第二个 Ubuntu 终端运行：

~~~bash
python3 web/gateway.py
~~~

在浏览器打开 http://127.0.0.1:8080/。首次使用时点击「注册」，填写用户名、邮箱和 8–64 个字符的密码。完成后使用用户名和密码登录。每个邮箱只允许注册一个账号。当前版本校验邮箱格式并保存地址，没有邮件验证码功能。网页的公共聊天室与终端客户端互通，点击右侧的在线成员即可发起私聊，「最近消息」查看最近 20 条公共记录，「群文件」查看和下载文件。公共聊天室底部的附件按钮用于上传文件。

网关只监听本机地址，使用 Python 3.9 或更新版本的标准库。自定义端口可用 python3 web/gateway.py --port 8081 --chat-port 9100 --data-dir ./demo-data，聊天端口和数据目录都要与 ./server 的配置一致。账号保存在数据目录的 accounts.sqlite3，密码使用 PBKDF2-HMAC-SHA256 加盐哈希保存。此前仅使用用户名加入聊天的成员需要先注册，原有聊天历史可继续读取。浏览器下载会在返回文件前进行 SHA-256 校验。需要从本地临时文件断点续传时，使用终端客户端的 /get 命令。

## 客户端命令

| 输入 | 操作 |
|---|---|
| 直接输入文字 | 发群聊 |
| /msg bob 你好 | 发私聊给 bob |
| /who | 列出在线用户 |
| /history 10 | 查询最近 10 条群聊和群文件记录，最多 20 条 |
| /upload ./实验记录.txt | 上传群文件，成功后群里会显示文件 ID |
| /get 文件ID ./下载记录.txt | 下载到指定路径 |
| /help | 查看命令 |
| /quit | 退出 |

上传或下载时可以继续聊天。一个客户端一次处理一个文件任务，文件上限为 1 GiB。下载过程中断后，重新登录并用相同的文件 ID 和目标路径执行 /get，客户端从旁边的 .part-文件ID 临时文件续传。通过 SHA-256 校验后，客户端才生成最终文件。若提示校验失败，可移走对应临时文件后重新下载。

## 多进程与数据流

- chat_server.c 为每条聊天连接创建一个读取子进程。子进程解析 TCP 帧，把请求送入 System V 消息队列，并通过唤醒管道通知父进程。父进程维护在线表，处理广播和定向投递，每个客户端有独立的待发送缓冲。
- protocol.c 将版本、消息类型和正文长度按网络字节序编码，接收端按长度恢复完整帧。
- transfer.c 使用独立的文件端口。文件子进程读取或写入文件，完成校验后提交群通知。聊天队列承载通知，文件内容直接经 TCP 传输。
- chat_client.c 处理终端输入和聊天收发，并在单独的子进程中执行文件任务。

运行数据默认写入 chat-data/。history.log 保存群聊和群文件通知，私聊只向参与者投递。files/ 保存按文件 ID 存放的数据和元信息。按 Ctrl+C 停止服务端，会回收子进程及消息队列。聊天和文件连接使用明文 TCP，用户名用于标识会话，适合本机或可信实验网络。
